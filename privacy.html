Pengelola dan tujuan

Aldo Baran adalah asisten pribadi untuk pekerjaan marketing pemilik akun. Kontak pengelola: kolspecialistruselco@gmail.com. Data digunakan untuk menjalankan instruksi pemilik, menyusun worksheet, menganalisis informasi, dan menghasilkan dokumen kerja.

Data Google yang diakses

Dengan persetujuan OAuth, aplikasi dapat mengakses informasi file di Drive, isi dan struktur Google Sheets, serta dokumen Google Docs. Izin tersebut mencakup membaca, membuat, mengubah, dan menghapus file. Pelaksanaan pekerjaan dibatasi oleh instruksi pemilik; penghapusan sumber memerlukan otorisasi yang berlaku untuk tindakan tersebut.

Pemrosesan dengan AI dan WhatsApp

Instruksi dan materi yang relevan untuk tugas dapat diproses oleh model AI yang dipilih melalui perantara (router) lokal. Penyedia model dapat mencakup OpenAI atau layanan model lain yang dikonfigurasi pemilik. Kebijakan dan kontrol data penyedia tersebut berlaku terhadap materi yang dikirim. Pemilik perlu memastikan konfigurasi penyedia sesuai dengan batasan data pekerjaannya.

Jika pemilik menggunakan WhatsApp, pesan dan hasil yang dikirim melalui percakapan tersebut juga diproses oleh WhatsApp sesuai kebijakannya. Gateway Aldo dikonfigurasi untuk percakapan pemilik dengan dirinya sendiri, bukan untuk menanggapi kontak atau grup lain.

Penyimpanan dan keamanan

Token OAuth disimpan sebagai file privat di Mac pemilik. Riwayat percakapan, bahan analisis, log operasional, dan hasil pekerjaan dapat tersimpan di perangkat pemilik. Token tidak ditampilkan dalam jawaban atau dimasukkan ke halaman publik ini. Data lokal tetap tersimpan hingga pemilik menghapusnya; tidak ada jadwal penghapusan otomatis yang dikonfigurasi saat ini.

Batas penggunaan

Aldo tidak menjual data Google atau menggunakannya untuk penargetan iklan. Aplikasi tidak menjalankan proses pelatihan model AI umum atas data Google. Data digunakan untuk fitur asisten yang diminta pemilik. Penggunaan dan pembagian data Google harus mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Pencabutan akses dan penghapusan

Pemilik dapat mencabut izin Aldo melalui pengaturan koneksi aplikasi pihak ketiga di akun Google. Pencabutan menghentikan akses Google berikutnya, tetapi tidak otomatis menghapus file, hasil kerja, atau riwayat yang sudah tersimpan secara lokal. Pemilik dapat menghapus data lokal atau menghubungi pengelola untuk bantuan.

Hosting halaman informasi

Halaman informasi ini menggunakan GitHub Pages. Saat halaman publik di GitHub Pages dikunjungi, GitHub mencatat dan menyimpan alamat IP pengunjung untuk keamanan, sesuai dokumentasi GitHub Pages dan kebijakan privasi GitHub.

Perubahan

Informasi ini harus diperbarui jika layanan, penyedia model, cara penyimpanan, atau penggunaan data berubah.
